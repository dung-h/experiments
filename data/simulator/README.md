# Local simulator evidence

These measurements were collected by this project. The directories separate
engines and execution clocks; they are not interchangeable runtime targets.

| Directory | Measurement context |
| --- | --- |
| `aer/` | Noisy Qiskit Aer execution, compiled/source features and predictor outputs |
| `statevector/` | CUDA-Q dense statevector sampling, FP32 and FP64 |
| `mps/` | CUDA-Q fixed-bond and joint runtime/quality measurements |
| `qcsim/` | Maestro-style optimizer-off QCSim component study |
| `tensor_network/` | cuTensorNet selected-plan estimates and matching contractions |
| `analog/` | Pasqal EMU-MPS analog companion with reference/candidate fidelity checks |
| `circuits/` | Circuit identities and panel membership, not circuit bytes |

Saved attempts include successful measurements and technical failures. Targets
and predictions retain the recorded context, folds and quality eligibility.
The [measurement guide](../../docs/training_and_measurement.md) documents timing
boundaries, repetition reductions, resource limits and environment evidence.

Source paths and hashes identify external circuit inputs. QASM archives,
serialized source graph payloads, SDK binaries, checkpoints and environments
are not included. Some run manifests refer to those external or private files;
their hashes record provenance, not current file availability.

The QCSim plan includes the synthetic 1Q/2Q/sampling calibration programs
generated by this project's calibration code. Those are not copies of the
source circuit archive.
