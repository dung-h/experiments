# Ma--Li compact physical-DAG corpus

This artifact is a `CURRENT_FAKE_SNAPSHOT_PROXY`. It transpiles the Ma--Li
logical QASM with FakeOsaka/FakeKyoto under the frozen Qiskit protocol and
stores one compact NPZ graph per `(QASM hash, backend)` cell. The observed
`result.time_taken` labels are kept in `manifest.csv`; they are not treated
as a duration generated by the fake target.

- label rows: **340**
- unique physical graphs: **300**
- native operation nodes: **67404145**
- dependency edges: **79673830**
- maximum active physical width: **127**
- duration-missing nodes: **0**

Each graph stores native opcode, physical qargs, target duration in dt,
gate-error availability, topological layer, forward/reverse weighted path,
criticality, dependency wire and dependency kind. Zero-duration `rz` is
retained as a valid target property; it is not marked missing.

The graph is suitable for a static QCRE residual or a small directed DAG
model. It does not establish historical physical-circuit truth, and it
must be evaluated with the grouped-QASM/strict backend splits in the
deep protocol document.

The companion `baseline_evaluation/` directory contains the QCRE, compiled,
physical-count and rich-static gates. `feature_ablation/` adds layer, timing,
edge and opcode blocks under the same folds. `qwalk_forensics/` keeps the two
QWalk rows as a tail/OOD diagnostic with feature-support distances and OOF
predictions; it is not an independent score.
