partial summaries for current interpretation. They do not overwrite historical

CSV values are unchanged. Aggregate JSON views omit private/input metadata keys
without altering retained values. Absent source evidence is explicitly marked

## What stays local

tensors, checkpoints, source QASM, upstream checkouts, environments, process
logs/workers and redundant metric registries. Mixed-context pilot/Phase-2 raw
files are excluded to avoid redistributing their QPU rows. Superseded evidence
and unrelated development edits are preserved locally, not swept into Git.

## Verification

Run the commands in the root README. The completed-science checker verifies
export hashes, aggregate QPU/source-weighted values, RQ-closure consistency and
the six matched accuracy–cost rows. It recomputes Dense subset MAE and B2
medians from the project's published records without model inference or timing.
Public tests run independently of the original private scientific fixtures.

Original support scripts and tests are retained for source review; they still
require their historical environments, development layout and excluded inputs.
They are not advertised as self-contained public QPU refit commands. Full local
suite PASS and source-pins validation are distinct from this clean-checkout
public verification. Neither establishes independent QPU retraining reproduction.

No new experiment, training, inference, timing or quantum execution is part of
this publication. No Canva modification occurred. License/author metadata
remains an explicit limitation of formal release, not a claim about new
scientific evidence.
