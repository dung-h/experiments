# Data and code availability

Local simulator measurements, technical failures, quality records, saved
predictions and aggregate results are included. These were generated by this
project, not copied runtime labels from the papers.

The Ma–Li, Qonductor and QPack real-QPU source datasets are not redistributed.
Their row-level derived QPU inputs and outputs are also excluded. The repository
documents how these sources were joined, normalized, reconstructed and evaluated,
and reports aggregate results. Source circuit archives, serialized circuit DAGs
and native SDK binaries are not included.

The [upstream metadata](../provenance/upstream.json) records source revisions.
The [publication selection](../provenance/publication.json) lists the included
and omitted paths. Recorded paths inside experiment metadata refer to the
original workspace; they are not bundled datasets.

`methods/` contains project implementations and wrappers around external
libraries and pinned upstream helpers. Those external components keep their
own terms. See [source notices](../NOTICE.md). No blanket license for upstream
code or third-party datasets is granted by this repository.

The project code has no root license selected yet. Citation metadata and a
project-wide code license can be added separately; they do not change the
recorded experiment or the data exclusions.
