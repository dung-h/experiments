# Provenance labels

| Label | Meaning |
| --- | --- |
| AUTHOR_ARTIFACT | Supplied by an upstream repository or paper |
| DERIVED_RECOMPUTE | Metric recomputed by us from an author artifact |
| OUR_REPLICATION | Script/output produced by our environment |
| OUR_PROXY | Substitute for an unavailable historical service, calibration or live backend |

OUR_PROXY is not a weaker wording for hardware replication. It is a different
evidence class. Ma–Li fake backend properties and CDAA offline Qiskit/TKET
compilation remain useful only when named as proxies.
